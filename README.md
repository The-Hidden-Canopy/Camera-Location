# Camera-Location

Camera-Location is The Hidden Canopy's local physical-infrastructure discovery
and location utility. It helps identify network-visible cameras, NVRs, radios,
switches, edge hosts, and legacy devices while preserving the difference
between declared, observed, verified, and authorized state.

## Boundaries

- Discovery creates evidence, not trust.
- A device seen on the network is not automatically a trusted device.
- Discovery is not authorization.
- An IP address is not a durable identity.
